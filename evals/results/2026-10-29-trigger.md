# Trigger test results, 2026-10-29

Does Claude Code load the skill for a request? Each prompt in `evals/trigger-prompts.tsv` ran once in a fresh copy of ts-shop with the skill installed, read-only tools, and a $1 cap (`evals/trigger-test.sh`). Claude Code 2.1.312, Opus 5.5.

## Round 1: description at `ad0a2ee`

Write-mode trigger: "writing new code that processes large or growing collections, runs in hot paths (per request, per frame, per item), queries databases or services in loops, or needs a data-structure choice."

| Group | Loaded | Correct |
|---|---|---|
| Existing code (S1–S4) | 4 of 4 | 4/4 |
| New code (W1–W8) | 4 of 8 | 4/8 |
| Trivial (N1–N8) | 0 of 8 | 8/8 |

Correct: 16 of 20. Cost: $4.46.

The four write-mode prompts that loaded the skill each stated a size or frequency ("about 150,000 invoices a month," "every keystroke," "about 25,000 movements a night") or an obviously quadratic task ("every pair of customers"). The four that missed (W1 stock valuation, W2 top 10 SKUs, W7 per-request permission check, W8 merging supplier price lists) did not, although `src/volumes.ts` gives the sizes. The agent decided from the wording of the request, not from the project's data.

## Round 2: description changed to the shape of the task

Write-mode trigger: "writing new code that aggregates, searches, sorts, ranks, joins, merges, deduplicates, or groups collections, runs per request, per item, per frame, or per keystroke, calls databases or services in loops, or needs a data-structure choice, even when the request does not mention size or speed."

Rerun of the four misses and all eight trivial prompts:

| Prompt | Round 1 | Round 2 |
|---|---|---|
| W1 stock valuation | missed | **loaded** |
| W2 top 10 best-selling SKUs | missed | **loaded** |
| W7 per-request permission check | missed | missed |
| W8 merge supplier price lists | missed | **loaded** |
| N1–N8 trivial | none loaded | none loaded |

Correct: 11 of 12. Cost: $2.59. Combined with the unchanged round 1 results for S1–S4 and W3–W6 (not rerun), the estimate is 19 of 20.

W7 still did not load. In this fixture, permission lists are capped at 40 (`src/permissions.ts`), so a simple scan is arguably the right answer, and the eval answer key for the same code (T7) accepts "not worth changing." W7 is a weak test of triggering and should be replaced by a prompt where the size clearly matters.

## Limits

One run per prompt; a single hit or miss can be chance. S1–S4 and W3–W6 were not rerun with the new description. Next: three runs per prompt over the full set, and replace W7.
